## Demo Upgrade Roadmap

The current GitHub Pages surfaces make every strong project clickable. The next improvement is to turn the best static surfaces into full interactive apps.

| Project | Next demo upgrade |
| --- | --- |
| Holup | Public leaderboard with model filters, failure-mode charts, and downloadable result JSON. |
| DEIC | Interactive simulator for hidden-state belief updates, query budget, and trust collapse. |
| Kathakaar | Hugging Face Spaces or Gradio demo with grounded story generation and sample voice output. |
| Cons.trukt | Streamlit document demo using sample blueprint/borehole files and risk ledger output. |
| Healing Stones | Three.js artifact viewer showing fragment alignment, before/after states, and metrics. |
| Sonish v2 | Vercel frontend plus Render/Railway backend with demo credentials and seed catalog data. |

## Current Direction

I am focusing the portfolio around research-to-product AI systems: small enough to inspect, serious enough to show original thinking, and polished enough that a recruiter can understand the value without a live walkthrough.
