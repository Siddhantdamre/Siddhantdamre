# Siddhant Damre

AI/ML builder focused on metacognitive agents, reasoning benchmarks, cultural AI, and practical full-stack systems.

I like building systems that make uncertainty visible: when a model should answer, abstain, escalate, retrieve more context, or recover from a bad assumption.

## Focus

- Metacognitive reasoning, uncertainty-aware evaluation, and agent behavior
- Retrieval, OCR, and multimodal AI for real-world workflows
- Cultural and public-interest AI applications
- Full-stack products with practical backend, frontend, and data pipelines
